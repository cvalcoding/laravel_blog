
# Laravel blog

Le but de ce projet est de pouvoir faire une application blog qui va permettre de voir :
- Les base de laravel
- La construction d'une api
- La mise en place d'un front end avec React et Bootstrap
- Des tests unitaires
- Les bonne pratiquent de laravel

## Installation

- cloner le projet et depuis un terminal entre dedans
- créer un fichier **.env** avec la commande: **cp .env.example .env**
- créer la base de donnée 
- taper la commande : **php artisan key:generate**
- puis la commande: **php artisan migrate --force**
- et enfin la dernière commande : **npm install && npm build**
